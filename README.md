# Назначение Смен — VK Mini App

https://modernbarbarian.github.io/vk-shift-app/

Мини-приложение для назначения смен сотрудникам в ВКонтакте.
Работает и как обычная веб-страница (GitHub Pages), и внутри ВК — как мини-приложение в iframe.

## Что реализовано
- **Сотрудники** — ввод имени вручную или выбор из друзей ВК (через `VKWebAppGetFriends`).
- **Смена** — сотрудник + дата и время + точка магазина. Точка запоминается и подставляется в следующие смены (список используемых точек).
- **График на неделю** — смены группируются по дням (пн–вс), можно перелистывать недели, удалять смены.
- **Календарь** — напротив каждой смены кнопка 📅, которая отдаёт файл `.ics`. Открытие файла добавляет событие в календарь телефона (iOS — Календарь, Android — Google Календарь).
- **Рассылка** — текст графика для каждого сотрудника, копируется в буфер обмена, чтобы отправить сотруднику в личные сообщения ВК.
- **Статистика месяца** — отдельная вкладка: для каждого сотрудника количество смен и сумма часов за текущий месяц.
- **Дизайн** — белый фон, голубые кнопки, минималистичный стиль, адаптация под мобильные экраны и тёмную тему ВК.

## Интеграция с VK Bridge
Модуль `js/vk.js` — единственная точка касания с клиентом ВК (`js/vk-bridge.min.js` — локальная копия [@vkontakte/vk-bridge](https://github.com/VKCOM/vk-bridge) v3.0.2, без зависимости от CDN).

| Возможность | Событие | Поведение вне ВК |
|---|---|---|
| Инициализация мини-приложения | `VKWebAppInit` | не выполняется |
| Тема и safe-area инсеты | `VKWebAppGetConfig` / `VKWebAppUpdateConfig` | используется системная тема и `env(safe-area-inset-*)` |
| Цвет статус-бара и шторки | `VKWebAppSetViewSettings` | не выполняется |
| Друзья для выбора сотрудника | `VKWebAppGetFriends` | подсказка «введите имя вручную» |
| Копирование графика | `VKWebAppCopyText` → `navigator.clipboard` → окно с текстом | обычный буфер обмена / окно с текстом |
| Скачивание `.ics` | `VKWebAppDownloadFile` → `<a download>` → копирование `.ics` | `<a download>` |
| Данные на всех устройствах | `VKWebAppStorageGet` / `VKWebAppStorageSet` | только `localStorage` |

Ключевые особенности:
- **Все вызовы bridge идут с таймаутом** — клиент ВК молча не отвечает на неподдерживаемые методы, без таймаута Promise «зависает» навсегда.
- Методы проверяются через `supportsAsync`, недоступные молча заменяются запасным вариантом.
- Результат `VKWebAppGetFriends` читается из `res.users` (в старых версиях было `res.items`) — сейчас используются оба варианта.

## Адаптация под iframe мини-приложения
- **Нет `window.top`, `window.open`, `target="_blank"` и любых прямых переходов** — общение с ВК идёт только через bridge, скачивание файлов происходит в той же вкладке.
- `alert()`/`confirm()` заменены на свои модальные окна и toast-уведомления: нативные диалоги в iframe ВК отображаются некорректно.
- `viewport-fit=cover` + отступы из `VKWebAppUpdateConfig.insets` (вырез/«челка», нижний индикатор Home) применяются к шапке, FAB, футеру и модальным окнам.
- Высота окна на `100dvh` — интерфейс не «плывёт», когда внутри iframe открывается клавиатура; активное поле ввода автоматически скроллится в видимую область.
- `overscroll-behavior-y: none` — отключён pull-to-refresh внутри мини-приложения.
- Тёмная тема клиента (`appearance: dark`) включается через `data-appearance` на `<html>`.
- Скачивание `.ics` в нативном клиенте идёт через `VKWebAppDownloadFile`, при неудаче — обычное скачивание и модальное окно с содержимым файла («Скопировать .ics» / «Повторить»).

## Данные
- Основное хранилище — `localStorage` (работает всегда и на GitHub Pages).
- Внутри ВК состояние дублируется в **VK Storage** (`vkshifts_state`), поэтому график открывается на любом устройстве, где пользователь запускает мини-приложение.
- Конфликт решается по полю `updatedAt`: побеждает более новая версия, при старте более новая версия подтягивается и перерисовывается.
- Запись в VK Storage отложена на 1.5 с после изменений (не дёргаем клиент на каждое нажатие), значения больше ~60 КБ не отправляются (лимит VK Storage — 64 КБ).
- Для совместной работы всей команды (несколько администраторов с разными правами) по-прежнему нужен бэкенд и авторизация через VK ID — VK Storage привязан к пользователю, а не к группе.

## Как запустить
1. Поместите файлы на любой хостинг с **HTTPS** (требование VK Mini Apps), например GitHub Pages, VK Хостинг для мини-приложений или свой сервер.
2. В группе ВК создайте мини-приложение (Управление группы → Мини-приложения → Создать) и укажите ссылку на `index.html`.
3. Откройте приложение внутри ВК (мобильное приложение, m.vk.ru или vk.ru).
4. Проверить, что всё подключилось: в приложении кнопка 👥 должна открывать список друзей, а уведомления показывать «Скопировано в буфер обмена ВК».

Локально приложение запускается обычным статическим сервером:
```bash
python3 -m http.server 8000
```

## Структура
```
index.html            разметка
css/style.css         стили + safe-area + тёмная тема
js/vk-bridge.min.js   VK Bridge v3.0.2 (локальная копия)
js/vk.js              обёртка над bridge: инициализация, тема, друзья, копирование, файлы, VK Storage
js/app.js             бизнес-логика приложения (график, статистика, рассылка, .ics)
```

## Технологии
- Чистый HTML/CSS/JS, без фреймворков и сборки
- [@vkontakte/vk-bridge](https://github.com/VKCOM/vk-bridge) — взаимодействие с клиентом ВК
- Файлы календаря по стандарту iCalendar (`.ics`)

### Обновление VK Bridge
```bash
npm pack @vkontakte/vk-bridge@latest
tar -xzf vkcom-vk-bridge-*.tgz package/dist/browser.min.js
cp package/dist/browser.min.js js/vk-bridge.min.js
```

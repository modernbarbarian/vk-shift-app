# Назначение Смен — VK Mini App

Мини-приложение для назначения смен сотрудникам в ВКонтакте.

## Что реализовано
- **Сотрудники** — можно ввести имя вручную или выбрать из друзей ВК (через `VKWebAppGetFriends`).
- **Смена** — сотрудник + дата и время + точка магазина. Точка запоминается и подставляется в suivantes сменах (список используемых точек).
- **График на неделю** — смены группируются по дням (пн–вс), можно перелистывать недели, удалять смены.
- **Календарь** — напротив каждой смены кнопка 📅, которая скачивает файл `.ics`. Открытие файла добавляет событие в календарь телефона (iOS — Календарь, Android — Google Календарь).
- **Рассылка** —形成 текст графика для каждого сотрудника, копируется в буфер обмена, чтобы отправить сотруднику в личные сообщения ВК.
- **Статистика месяца** — отдельная вкладка: для каждого сотрудника количество смен и сумма часов за текущий месяц.
- **Дизайн** — белый фон, голубые кнопки, минималистичный современный стиль, адаптировано под мобильные экраны.

## Как запустить
1. Поместите файлы на любой хостинг с **HTTPS** (требование VK Mini Apps), например GitHub Pages, VK Хостинг для мини-приложений или свой сервер.
2. В группе ВК создайте мини-приложение (Управление группы → Мини-приложения → Создать) и укажите ссылку на `index.html`.
3. Откройте приложение внутри ВК (мобильная версия / приложение ВК).

## Данные
Пока данные хранятся в `localStorage` браузера (только на этом устройстве). Для совместной работы всей команды нужен бэкенд (например, на Node.js/PHP + база данных) и авторизация через VK ID.

## Технологии
- Чистый HTML/CSS/JS (без фреймворков)
- [@vkontakte/vk-bridge](https://github.com/VKCOM/vk-bridge) — работа с VK (инициализация, друзья)
- Файлы календаря по стандарту iCalendar (`.ics`)
